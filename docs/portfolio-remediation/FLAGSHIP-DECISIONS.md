# Flagship Decisions

The primary reviewer path contains only five assets: ProcessHarbor, RedactReady, WeaveStudio, QuoteForge Local, and BuildWorld AI.

- **ProcessHarbor** is the canonical public product name for the `opspilot-ai-operations-toolkit` workspace. “OpsPilot” is a legacy implementation alias, retained only where a path or historical deployment requires it.
- **RedactReady** is the canonical privacy workflow. RedactReady Pro/HRI OS is supporting/experimental material, not a competing flagship.
- **WeaveStudio** source authority is the separate `atomicdjt/weavestudio` repository. The public acquisition reference uses the `weavestudio-nine` surface; provider-side verification remains required.
- **QuoteForge Local** is a commercial source-code product. Commercial packaging does not evidence sales, customers, or results.
- **BuildWorld AI** is the fifth flagship because a separate authoritative repository, deterministic tests, and reproducible local build were verified in this remediation pass. ScamShield AI remains supporting proof.

All other projects are supporting, experimental, legacy, archived, or creator-lane work. This is a portfolio-navigation decision, not a deletion, archival, or provider action.
