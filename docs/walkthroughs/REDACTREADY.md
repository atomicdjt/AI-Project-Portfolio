2. Load a supplied synthetic sample; never use real sensitive files in a public demo.
3. Inspect masked findings and demonstrate a human approval/rejection or manual visual box.
4. Show the verification checklist and explain why visual, selectable, metadata, filename, and OCR risks remain.
5. Export a flattened review copy and optional masked report.
6. Open the export separately and confirm that manual inspection is still required before sharing.
