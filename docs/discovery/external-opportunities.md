# External Discovery Opportunities

Checked: 2026-08-16
Owner: David Turner (`atomicdjt`)

## Goal

Create legitimate, public, crawlable discovery paths from developer, product, and professional communities back to David Turner's canonical portfolio and strongest projects. Quality and audience fit take priority over submission volume.

## Ranking method

Each opportunity is scored qualitatively on audience relevance, public/indexable value, project fit, maintenance cost, and submission friction. A listing is not counted as a backlink until a public URL exists.

## Official rules checked

### Hacker News — Show HN

Official: https://news.ycombinator.com/showhn.html

- The submission must be something the maker personally built that people can actually try.
- The project should be non-trivial and the maker should be available to discuss it.
- HN recommends removing signup/email barriers where practical.
- Landing pages, fundraisers, and reading-only material are not Show HN submissions.
- Do not ask friends or communities to upvote or comment.

**Fit decision:** BuildWorld AI is the strongest first candidate. It is a usable application, not a waitlist or landing page, and has enough architecture/methodology material to support a technical discussion.

### Product Hunt

Official:
- https://help.producthunt.com/en/articles/479557-how-to-post-a-product
- https://help.producthunt.com/en/articles/9883485-product-hunt-featuring-guidelines
- https://help.producthunt.com/en/articles/481909-how-can-i-get-access-to-post
- https://help.producthunt.com/en/articles/2690626-how-do-i-share-my-post

- A personal account is required to post; company accounts cannot post/vote/comment.
- New accounts normally wait one week before posting unless Product Hunt's current onboarding shortcut applies.
- The product should link directly to the actual product and live products receive the strongest consideration.
- A regular launch is free; paid promoted placement is not required and is not part of this program.
- Product Hunt evaluates usefulness, novelty, craft, creativity, and authentic engagement.
- Do not mass-message or coordinate upvotes.

**Fit decision:** WeaveStudio is the strongest first candidate because the live canvas is immediately understandable and testable, with product screenshots and a clear maker story.

### Peerlist Launchpad

Official:
- https://help.peerlist.io/individual/launchpad/how-to-launch-a-project-on-peerlist-launchpad
- https://help.peerlist.io/individual/launchpad/guidelines-faqs

- Launchpad requires a Verified individual Peerlist profile.
- The project page must be 100% complete.
- Launches occur weekly and can be scheduled.
- Spam and unsolicited upvote requests are prohibited.

**Fit decision:** valuable if David can satisfy verification without paying solely for exposure. Do not create or verify an account automatically.

### Hashnode

Official:
- https://docs.hashnode.com/blogs/editor/writing-a-blog-post
- https://docs.hashnode.com/blogs/blog-dashboard/github/publish-from-github

- Hashnode supports SEO title/description fields and original canonical URLs.
- It supports publishing Markdown from GitHub through its GitHub integration.

**Fit decision:** use for a substantive technical case study, not duplicated promotional copy.

### AlternativeTo

Official: https://alternativeto.net/faq//

- Users can suggest a new application through the site.
- New accounts must wait one week before submitting a new app.
- Entries are reviewed before approval.

**Fit decision:** useful second-wave corroboration once an eligible account exists and the comparison set is defensible.

### SaaSHub — deferred

Official: https://www.saashub.com/services/submit

SaaSHub currently rejects products using free hosting subdomains such as Vercel subdomains. The current canonical products use `*.vercel.app`, so do **not** spend time submitting them now. Revisit only if a custom domain is adopted for independent reasons.

## Rejected tactics

- Paid backlink packages or paid directory placement solely for SEO.
- Bulk directory submission services.
- Reciprocal-link schemes.
- Fake reviews, stars, votes, comments, followers, testimonials, customers, or traffic.
- Mass cold email/DM campaigns.
- Copy-pasting the same promotional post into unrelated communities.
- Buying a custom domain solely to satisfy a directory requirement before there is evidence that the directory is worth the migration.

## Recommended publication sequence

1. **Show HN: BuildWorld AI** — strongest technical-discussion fit.
2. **Product Hunt: WeaveStudio** — strongest polished-product fit.
3. **Hashnode or DEV: Validation Ledger case study** — strongest durable technical-writing/backlink fit.
4. Refresh **LinkedIn headline/About/Featured** so people arriving from any of the above see the current body of work.
5. Add AlternativeTo/Peerlist only after their account/verification prerequisites are satisfied.

The sequence deliberately mixes discovery intents: technical peers, product users/builders, indexed technical writing, and professional/recruiter conversion.
