BuildWorld AI — Systems Simulation Lab

A browser-based lab for designing explicit graph models, running deterministic or seeded scenario experiments, inspecting bottlenecks and cascades, and reproducing results from recorded model inputs.

Open simulation labInspect sourceMethodology

What it explores

BuildWorld AI is designed for scenario reasoning in graph-based systems. Users can change topology and parameters, run built-in or custom scenarios, inspect critical nodes and bottlenecks, compare variants, and export reports that retain the assumptions behind the result.

Example models cover traffic, supply chains, power grids, ecosystems, warehouses, epidemics/population, emergency-resource networks, and custom graphs.

Reproducibility contract

  • Reports record model/version information, input fingerprints, graph inputs, and seeded variation where applicable.
  • Multi-seed ranges can expose model sensitivity instead of presenting one run as uniquely authoritative.
  • The System Stability Index is an original inspectable heuristic, not a certified engineering or scientific metric.
  • The standard workflow runs in the browser and does not require a paid AI API.
  • Visual layout is treated as presentation unless the model itself encodes spatial meaning.

Evidence boundary

A BuildWorld result is a result of the implemented model and the assumptions supplied to it; it is not an observation of the external world. The project is not presented as a certified engineering simulator, infrastructure recommendation system, public-health forecast, financial model, or safety-critical decision system.

One of the project's central review questions is where graph visualization can create perceptual meaning that the underlying model does not contain.
