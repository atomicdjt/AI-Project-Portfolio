WeaveStudio

A visual workflow canvas for turning fragmented notes, transcripts, logs, research material, and client inputs into structured deliverables that remain reviewable before export.

Open live productInspect sourceAcquisition overview

What it solves

Professional deliverables frequently begin as scattered source material. WeaveStudio makes the transformation visible: source content becomes editable workflow nodes, claims can retain links to captured source ranges, review gates stay explicit, and the final deliverable remains editable before export.

The intended users include researchers, analysts, project managers, and consultants who want a structured synthesis workflow without making a cloud backend mandatory.

Architecture and workflow

  • Visual workflow canvas built with React and React Flow.
  • Browser-local workspaces with autosave, named projects, snapshots, backup/restore, and portable Project JSON exports.
  • Claim-to-source provenance with direct, transformed, manual, or AI-assisted derivation labels and stale/broken reference detection.
  • Workflow Validator for structural gaps, review readiness, and export preparation.
  • Markdown, PDF, and re-importable project export paths.
  • Optional OpenAI/Gemini BYOK assistance is consent-gated per request and requires human review before applying generated output.

Evidence boundary

WeaveStudio is local-first in the sense that the normal workspace does not require an account, cloud database, or backend, but it does not claim built-in multi-device sync, real-time collaboration, or guaranteed offline operation after initial page loading. Browser localStorage is not encrypted durable cloud storage.

Provenance records workspace lineage; it does not prove external factual truth, source authenticity, or source quality.

The project is public for evaluation and portfolio review under a proprietary license. Public source visibility does not make it an open-source contribution target.
